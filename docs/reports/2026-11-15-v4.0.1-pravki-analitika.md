# Отчёт: две правки аналитика к заданию 08 (версия 4.0.1)

**Дата:** 15 ноября 2026. **Ветка:** `v4.0-5-god`. **Статус:** в пробной версии https://oreh-patrol.website.yandexcloud.net/preview/ (VERSION `oreh-v4.0.1`). В основную игру и на GitHub не выложено — ждёт «да».

## 1. Склонение после чисел
Проверил все новые задачи 5 класса (`js/t5b.js`). Исправлено:
- «Опросили 92 пятиклассников» → **«92 пятиклассника»** (диаграммы, 2 задачи);
- «3 множителей, 3 нулей» → **«3 множителя, 3 нуля»** (степени числа 10);
- «В саду 22 деревьев» → **«22 дерева»** (задачи на части);
- «4 делений» → **«4 деления»** (шкала с ценой деления).

В автотесте проверка склонений раньше знала только три слова (мешок, орех, гриб). Теперь в ней 17 слов из задач 5 класса, и прежнюю ошибку она ловит. Расширенная проверка нашла ещё одну ошибку, в старой локации «Объёмная мастерская»: «на дне 42 кубиков». Исправлено на **«42 кубика»**. Ещё одна нашлась в «Диаграммах»: «прочитала 87, 65, 82 страниц». Теперь слово согласуется с последним числом: **«82 страницы»**.

## 2. Одна подсказка на карте
Если в разделе для взрослых тема «Сейчас в школе» выбрана, на карте 5 класса остаётся только эта метка. «Сюда сначала!» не показывается. Итог Проверки сил в этом случае тоже не ссылается на «Сюда сначала!»: там написано просто «Их стоит повторить». Если тему не выбирали, всё как раньше.
