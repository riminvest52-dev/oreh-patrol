# Ореховый патруль

Игра-тренажёр по математике 5 класса (программа Л. Г. Петерсон, 1–2 четверть) с бурундуками Фундуком и Миндалинкой.
Работает на айфоне как приложение с иконкой (PWA), без интернета после первого открытия.

## Что внутри

| Локация | Тема |
|---|---|
| 🦔 Старый дуб | Фундамент: деление с нулём в частном, умножение, величины, периметр и площадь, «на сколько / во сколько раз» |
| 🦜 Поляна переводчика | Математический язык: чтение и запись выражений, «на … больше», «в … раз меньше» |
| 🐭 Мельница | Порядок действий, скобки, удобный счёт, буквенные выражения |
| 🦫 Мастерская моделей | Задачи → выражение/уравнение: движение, течение, части, сумма-разность |
| 🦇 Пещера уравнений | Уравнения (неизвестный компонент), проверка корня, метод проб и перебора |
| 🦉 Остров правды | Высказывания, «все» / «хотя бы один», контрпример, отрицание |
| 🐹 Ореховый склад | Делители, кратные, простые и составные, делимость суммы и произведения |
| 🦝 Сито | Признаки делимости на 2, 5, 10, 3, 9 (и на 6, 15) |

В каждой локации: уровни «Росток → Орешек → Дуб → Испытание», шпаргалка, пошаговый разбор каждой ошибки.
Задания генерируются заново каждый раз, поэтому «выучить ответы» не получится.

## Как выложить в интернет (один раз)

Нужен любой бесплатный хостинг с https. Проще всего — **GitHub Pages**:
1. Создать репозиторий на github.com и загрузить в него содержимое этой папки (кроме `dev/` — это тесты, они не нужны).
2. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
3. Через минуту игра будет доступна по адресу `https://<логин>.github.io/<репозиторий>/`.

## Как поставить на айфон

1. Открыть адрес игры в **Safari**.
2. Кнопка «Поделиться» → «На экран „Домой“» → «Добавить».
3. Запускать игру с иконки. Прогресс хранится на телефоне; у иконки и у Safari он раздельный — играть лучше всегда с иконки.

## Как поставить на Android

1. Открыть адрес игры в **Chrome**.
2. Меню ⋮ → «Установить приложение» (или «Добавить на главный экран») → «Установить». В Samsung Internet: меню ≡ → «Добавить страницу на» → «Главный экран».
3. Запускать игру с иконки.

## Игроки и прогресс

У каждого игрока свой прогресс, игрока выбирают при запуске. Сменить или добавить игрока: нажать на бурундука в левом верхнем углу карты.

Перенести прогресс вручную: ⚙️ → удерживать кнопку 2 секунды → «Перенести прогресс». На другом устройстве он объединится с уже накопленным.

## Где живёт игра

Основной адрес: https://oreh-patrol.website.yandexcloud.net/ (Yandex Object Storage, бакет `oreh-patrol`).
Старый адрес на GitHub Pages работает дальше и показывает «Игра переехала» с кнопкой, которая переносит прогресс всех игроков.

## Как обновить игру

1. Поменять файлы, в `sw.js` увеличить `VERSION` (например, `oreh-v3.4`).
2. Выложить в бакет: `python dev/deploy/deploy.py` (нужен Yandex Cloud CLI `yc`, один раз авторизованный через `yc init`; ключей в репозитории нет). Проверить без выкладки: `--dry-run`.
3. Выложить на GitHub: `git push`.

Файлы игры берутся из кэша телефона мгновенно и обновляются в фоне, index.html ждёт сеть не больше 3 секунд. Новая версия включается при следующем открытии игры.

## Проверка

`dev/test.html` — автотест генераторов: создаёт ~33 600 заданий и проверяет ответы, варианты и разборы.

`dev/test-merge.html` — автотест объединения прогресса с разных устройств. `dev/kv_server.py` — заглушка облака для проверки на компьютере.
